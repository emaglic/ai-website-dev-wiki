# Shared Repository Instructions

Before doing repository work, read and follow `AGENTS.md` in this repository's root. It is the authoritative guide; do not maintain a separate copy of its rules here.

Shared workflows are in `.agents/skills/<skill-name>/SKILL.md`: `setup`, `self-review`, and `uiux-self-review`. If native skill invocation is unavailable, read and follow the requested workflow explicitly. Do not initialize the project wiki unless the user requests `/setup` or its explicit file-based equivalent. Template maintenance must leave project wiki articles and logs untouched.
